# Billage 발표 자료

브라우저에서 `index.html`을 열면 됩니다.

## 조작

| 키 | 동작 |
|----|------|
| `→` `Space` `Enter` | 다음 |
| `←` `Backspace` | 이전 |
| `1`~`5` | 섹션 점프 (공통 / 회원 / 물품 / 대여 / 관리자) |
| `F` | 전체화면 |

## 담당 분할 (이름만 채우면 됨)

| 섹션 | 담당 | 내용 |
|------|------|------|
| 공통 | | 목적, 스택, 구조, 도메인 |
| A | | 회원 · 인증 · 마이페이지 · 포인트 |
| B | | 물품 · 카카오맵 |
| C | | 대여 · 반납 · 포인트 정산 |
| D | | 문의 · 관리자 |
